# Pantallas auxiliares — Demo comercial LeadFlow

Material estático de demostración; no forma parte del producto funcional LeadFlow.

Abrir `01-apertura.html` directamente en un navegador. Recorrer las cuatro pantallas con los enlaces **Anterior (Previous)** y **Siguiente (Next)**:

1. `01-apertura.html`
2. `02-problema.html`
3. `03-fallos.html`
4. `04-cierre.html`

No requiere servidor, JavaScript, instalación ni dependencias externas. Para grabación, usar una ventana de escritorio maximizada y ocultar elementos del navegador que no aporten a la demo.
