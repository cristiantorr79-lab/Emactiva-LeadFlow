## Uso recomendado

1. Presentar el problema empresarial y la solución mediante la presentación.
2. Mostrar la demo audiovisual cuando resulte pertinente.
3. Compartir el portafolio para profundizar en capacidades, evidencias y límites.
4. Continuar con un diagnóstico de las necesidades y sistemas del potencial cliente.

La compatibilidad con nuevos CRM, condiciones comerciales, despliegue y responsabilidades se evalúan según cada caso.
